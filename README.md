# jasenbtc-website

The official Jasen BTC personal website — Bitcoin, travel, projects, and the road ahead.

## Run locally

This is a dependency-free static site. Open `index.html` in a browser, or serve the repository root with any static file server.

## Structure

- `index.html` — page content and accessible navigation
- `styles.css` — responsive layout, colors, and visual design
- `script.js` — mobile navigation and current-year footer

## Deploy

Publish the repository root with any static hosting provider, such as GitHub Pages. No build step or package installation is required.
